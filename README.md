#  E-Commerce Web Application – Laravel Project

##  Description du projet
Ce projet est une application e-commerce développée dans le cadre du cours **Programmation Web 2** (2ème année Business Computing).

L’objectif principal est de concevoir une plateforme complète permettant la gestion de produits, utilisateurs, commandes et interactions entre utilisateurs, en respectant une architecture **Laravel MVC**.


##  Technologies utilisées
- Laravel (Framework PHP)
- PHP 8+
- MySQL
- Blade (Template Engine)
- Eloquent ORM
- XAMPP  (environnement local)


##  Fonctionnalités principales

###  Authentification
- Inscription / Connexion / Déconnexion
- Vérification email
- Réinitialisation mot de passe
- Gestion du profil utilisateur

###  Produits
- Ajout / modification / suppression de produits
- Gestion des catégories
- Upload d’images
- Description, prix et détails

###  Catalogue
- Affichage public des produits
- Recherche par mot-clé
- Filtrage par catégorie
- Tri (prix, date)


###  Commandes
- Passage de commandes
- Historique des commandes
- Gestion des statuts (En attente, Validée, Annulée)

###  Évaluations
- Système de notation
- Commentaires sur produits/vendeurs



##  Architecture du projet
- Models
- Controllers
- Views (Blade)
- Routes
- Middleware
- Migrations & Seeders


##  Base de données
Tables principales :
- users
- products
- orders
- order_items
- reviews
- messages





##  Sécurité implémentée
- Protection contre SQL Injection
- Protection XSS
- Protection CSRF
- Validation des formulaires
- Gestion des sessions sécurisées
